TRAXION / hypercopy repository inventory
=======================================

STATUS: NON-AUTHORITATIVE POINTER

This file intentionally no longer contains a manually maintained repository
snapshot. The previous static tree became stale and could direct audits or
incident response toward obsolete entrypoints.

The authoritative inventory for any investigation is the Git-tracked file set
at the exact commit being examined:

    git ls-files

For a deterministic human-readable tree, run from anywhere inside the checkout:

    python scripts/generate_repository_tree.py

The CI job `repository-tree` generates the same tree from the checked-out commit
and uploads `REPOSITORY_TREE.generated.txt` as a workflow artifact. Record the
workflow run and commit SHA together with that artifact when using it as audit
or incident-response evidence.

Do not use this pointer file as a repository snapshot.
